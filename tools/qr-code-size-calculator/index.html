Use the estimate to plan a proof, not approve a print run

This QR code size calculator gives a starting pattern width before its blank margin. Select the material, phone-to-code distance, content type and logo option. The result appears in inches and millimeters. Then allow space for the quiet zone and test your actual code at the final size.

A distance estimate cannot tell whether a phone will scan a particular print. The tool does not inspect your QR image, count its modules, or measure camera focus, glare, contrast or print quality. Keep the full print-sizing guide handy if you need to work through those factors.

How the calculator works

The tool starts with scan distance ÷ 10, using inches for both measurements. This is a layout heuristic, not a QR standard or a tested maximum scanning distance.

  1. Compare that result with the selected layout baseline: 0.8 inches for a business card, 1.5 for a flyer, 1.25 for a tabletop sign, 2 for a window sign, 3 for a poster, or 1 for “Something else.” Use the larger value.
  2. Multiply by 1.18 for the long-URL preset or 1.35 for the Wi-Fi/contact preset. Keep the value unchanged for the short-URL preset.
  3. If a logo is selected, multiply by 1.2. Round the final result up to the next quarter inch.

These baselines and multipliers are this tool’s planning choices, not measurements of your QR code or validated safety margins. For example, a business-card baseline of 0.8 inches rounds up to a 1-inch result. More encoded data can require more modules, but the content labels alone do not reveal the actual pattern density.

Does the size include the quiet zone?

No. The result is the pattern width; add the blank margin around it. A standard QR Code needs a quiet zone at least four modules wide on every side. A module is one small square in the pattern. Keep that space light and free of text, borders and artwork.

DENSO WAVE’s code-area guidance separates the pattern from its margin. GS1 UK’s sizing example also adds eight modules to the width: four on the left and four on the right. Its retail-specific size requirements are not universal limits for this tool’s general-purpose codes.

A worked example: allow room beyond the result

Suppose your actual pattern is 29 modules across and the calculator returns 2.5 inches. With a four-module margin on each side, the full image spans 37 modules. Its total width is 2.5 × 37 ÷ 29 ≈ 3.19 inches, or about 81 mm. Use your actual module count; 29 is an example, not an assumption the calculator can verify.

If your export already includes the quiet zone, preserve it and size the whole image accordingly. Do not crop the margin or place a 2.5-inch full image while assuming the pattern itself is 2.5 inches wide.

How many pixels does a printed QR code need?

For a PNG, follow the printer’s requested pixels per inch (PPI). Multiply the full printed image width, including its quiet zone, by that value. At 300 PPI, the example above needs about 957 pixels across. A 2-inch full image needs 600 pixels. These are resolution calculations, not scanning guarantees.

Printer DPI describes printer dots; image PPI describes image pixels. They are not the same measurement. Avoid enlarging a small screenshot. Use SVG when your printer accepts vector artwork, or export enough PNG pixels for the intended image size. Neither format compensates for an unreadably small pattern.

DENSO WAVE’s module-size guidance explains why printer resolution and scanner capability matter. The logo guide covers a separate risk: enlarging the print does not restore modules hidden by a logo.

Test the finished print

  1. Generate the final code with the real destination or payload, not a simpler sample.
  2. Place the image with its quiet zone intact. Print at actual size, then measure it; “fit to page” can change the result.
  3. Try more than one phone at the intended distance, in the actual lighting and placement. Include any glass, laminate, curve or stand.
  4. Check the destination as well as recognition. A page may require a login even when the QR pattern scans correctly.
  5. If it fails, change one factor and try again: more space, less styling, stronger contrast or a different position. The QR troubleshooting guide separates recognition failures from broken links.

Frequently asked questions

What is the minimum QR code size for print?

There is no universal minimum for every code, phone and printer. This calculator provides a starting pattern width for a proof, not a guaranteed minimum. Pattern density, quiet zone, distance, contrast and print quality all affect the result.

How big should a QR code be on a business card?

With the business-card preset, a 6-inch phone distance, a short URL and no logo, this calculator returns a 1-inch pattern width before the quiet zone. That is a planning result, not a claim that smaller codes cannot work. Test the actual printed card.

Does the calculator include the blank margin?

No. Add a quiet zone at least four modules wide on each side of the pattern. If the downloaded image already includes that margin, preserve it and size the whole image so the pattern remains at your chosen width.

Can I use this calculator for a QR code with a logo?

Yes, as a planning estimate. The logo option increases the estimated width, but a larger print cannot restore modules hidden by a logo. Test the actual design and remove the logo if it prevents reliable scanning.

Should I print a QR code as SVG or PNG?

Use SVG if your printer accepts vector artwork. For PNG, multiply the full image width in inches, including its blank margin, by the printer’s requested pixels per inch. Avoid enlarging a small screenshot and test the finished print.
