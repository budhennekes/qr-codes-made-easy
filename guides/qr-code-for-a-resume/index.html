How to Make a QR Code for Your Resume

By Bud Hennekes, who built QR Codes Made Easy. Updated August 2026.

Put a small QR code in the header or footer that links to your portfolio, LinkedIn profile, or personal site, never to information that exists only in the code. Applicant tracking systems parse text, not images, so a QR code is invisible to the software that screens most resumes first. Keep every essential detail written out, and let the code be a bonus, not a requirement.

The ATS problem no one mentions

Most resumes for a posted job pass through an applicant tracking system before a person ever sees them. That software works by parsing, extracting the text layer of your resume and sorting it into fields like name, dates, and skills. A QR code is a graphic, not text, so a parser has no path to "read" it. Anything you put only inside the code, a phone number, a portfolio URL, a certification, is invisible to that first automated pass.

That doesn't mean skip the QR code. It means treat it the way you'd treat a nice-to-have: useful to the human who eventually opens your resume, irrelevant to the software that decides whether it gets that far. Keep your phone number, email, and city written in plain text at the top, exactly as you would if the QR code didn't exist.

What the code should point to

The easy mistake is linking the code back to a copy of the resume itself. That's circular: the recruiter already has your resume in hand, so a code that just re-opens it adds nothing. Point it at something the resume can't hold.

Link to…When it's worth the space
A portfolio or work samples pageYou're in a visual, technical, or writing field where seeing the work matters more than reading about it
Your LinkedIn profileYou want a recruiter to see recommendations, a fuller history, or shared connections in one tap
A personal site or contact pageYou want a single, durable link you can update anytime, unlike the printed resume itself
A specific project or case studyOne piece of work says more about you than a general link would

My honest take: a link you control, like a personal domain or a page you can edit, ages better than a link to a platform profile you don't control the layout of. If you don't have your own site, LinkedIn or a portfolio platform is a fine second choice. Make the code

Open QR Codes Made Easy, leave Website selected, and paste the link you chose. Then:

  1. Start with dark on light. It reads fastest on a phone camera and matches a resume's black-on-white printing anyway.
  2. Skip the logo. A resume already has your name at the top; a logo on the code adds density without adding information.
  3. Download SVG. It stays crisp whether the resume is printed, viewed as a PDF, or opened on a phone. The code is built in your browser and never sent anywhere in between.

Where it goes on the page

Small and out of the way. A corner of the header next to your contact line, or a line in the footer, works better than a large code competing with your experience section for attention. Keep your written contact details as the primary path to reach you, and let the code sit quietly as an optional shortcut for someone already holding the page.

One-page resumes: if space is tight, the QR code is the first thing to cut. It never carries information your resume needs to work; it only adds a faster path to something extra.

Make it survive print and PDF

A resume gets printed, emailed as a PDF, and screenshotted more than almost any other document, so test all three. Export the resume, print one physical copy, and scan the code with a phone in ordinary light. Then open the PDF version on a screen and scan it directly off the display. Both should open the same link cleanly. Our QR print-size guide covers a safe minimum size for something this small; if either test fails, run through the troubleshooting checklist before sending the resume out.

FAQ

Will an ATS reject my resume for having a QR code?

No. It simply won't read the code. The parser processes the text on the page and ignores the graphic, so a QR code neither helps nor hurts automated screening as long as your written details are still complete.

Should the QR code link to a PDF of my resume?

Usually not. Whoever scans it already has the resume. Point the code at something it can't show, like a portfolio, work samples, or a fuller profile.

Is a QR code appropriate for every resume?

It fits best in visual, technical, or portfolio-driven fields where seeing work matters. In more conservative or traditional industries, a small code is still fine, but it should never replace a written link or contact line.

What size should the code be on a resume?

Small, roughly 0.5 to 0.7 inch is enough for a close-up scan in a corner or footer. Leave the quiet margin around it alone and test a printed proof before sending the resume out widely.
