How to Make a QR Code for a Restaurant Menu

By Bud Hennekes, who built QR Codes Made Easy. Updated September 7, 2026.

Put your menu at a stable web address, paste that address into the free generator, and download your QR code. Update the menu at the same address when prices change. The static code has no expiry date or subscription, but your menu page and domain must stay available.

Choose a menu address you control

Use a short address on your own domain, such as yoursite.com/menu. That address is the part you print permanently. The menu behind it can change.

Check the link in a private browser window before making the code. A customer should not need your account, a password, or permission to view the menu. Keep the domain renewed and the page online.

A shared document or third-party ordering page can work, but you do not control its domain. If you change providers or lose the account, the printed link may stop working. Prefer your own menu page when possible.

Mobile menu page or PDF?

Start with a mobile-friendly web page if you can. A PDF is a practical option when you already have a readable menu file. Test either format on a phone before deciding.

FormatUseful whenCheck before printing
Mobile web pageYou want readable text that fits a phone screen and prices you can edit.Text size, load time, current prices, and access without signing in.
PDF on your siteYou already have a menu file and can replace it at the same URL.File size, zooming, download behavior, and whether a replacement changes the URL.
Shared documentYou need a simple starting point without building a page.Public viewing permissions, phone layout, and long-term access to the owning account.

The code stores the link, not the menu file. A larger PDF does not automatically make the QR pattern denser, but it can take longer for diners to open. See the PDF QR code guide for file-link checks.

Don't have a menu page yet?

First check whether your existing website can add a menu page. If you need a new site, compare builders such as Squarespace and Carrd. Check the current plan's custom-domain and publishing options before paying.

Make your QR code

  1. Open the free QR code generator and choose Website link.
  2. Paste the full public menu URL. Check the spelling and destination.
  3. Use a dark code on a light background. Add a small logo only if you need it.
  4. Download SVG for a printer or designer who accepts vector files. Use PNG when your layout tool needs an image.
  5. Keep the blank margin around the pattern when placing the code in your layout.

The generator raises error correction when you add a logo. That adds redundancy; it does not guarantee a scan. A large logo, poor contrast, or a small print can still make the code fail. Read the logo-size guide before approving branded artwork.

Update the menu without reprinting

Edit the content at yoursite.com/menu and leave the address unchanged. The same printed code will open the updated page.

If you link directly to a PDF, replace the file at the same URL. Uploading a new file with a new name does not update the old QR code. Linking to a stable menu page instead gives you a place to swap files or add seasonal menus.

Keep a fallback. Print the readable menu address next to the code and keep a paper menu available for customers who cannot or prefer not to scan.

Choose a print size

For a close-up table-tent scan, a code around 1.2 to 2 inches square is a starting point, not a guarantee. Use the QR print-size calculator to account for the expected distance, content density, and logo use. Larger codes may be needed.

Leave the generator's blank border intact. DENSO WAVE specifies a four-module margin around a standard QR Code. A module is one small square in the pattern. Do not let text, artwork, or a trim line enter that margin.

Restaurants can be dim, and glossy holders can reflect overhead lights. Test the code inside the holder you intend to use, at an actual table. The print-size guide explains sizing in more detail.

Test a printed proof before ordering

  1. Print the final artwork at its intended size. Do not test only the QR preview on your monitor.
  2. Place the proof in the actual holder, sleeve, or table tent.
  3. Scan it with more than one phone, ideally including an iPhone and an Android phone.
  4. Test from the diner's seat under normal service lighting. Check for glare.
  5. Open the menu over mobile data as well as guest Wi-Fi. Confirm it loads without signing in.
  6. Check the menu's prices, readable text, and fallback address before approving a print run.

If a test fails, fix the cause and print another proof. Start with QR scan troubleshooting. This checklist is a test procedure, not a claim that every size, phone, or holder has been tested by us.

Do you need a dynamic code?

Usually not for a menu you can update at a stable address. A static code links directly to that address without a QR provider's redirect in between.

A dynamic service can be useful if you need to change the encoded destination through its dashboard or use its reporting tools. The tradeoff is dependence on that service. Check its free-plan limits, cancellation terms, and what happens to printed codes if you stop paying.

For campaign reporting, Google's UTM parameters can identify visits from a tagged menu link in analytics you already run. This is not an exact scan count: people can scan without opening the page, share a tagged link, or block analytics. Follow the QR visit-tracking guide for setup and limitations. Do not put customer information in the tags.

FAQ

How do I make a free QR code for my menu?

Put your menu at a public URL, paste it into the generator, and download the code. Test the final print before ordering. No account or QR subscription is required.

Do menu QR codes expire?

A static QR code has no expiry date, but its menu page and domain must stay available. A dynamic code depends on the redirect service and its terms.

What size should a menu QR code be on a table tent?

For close-up use, around 1.2 to 2 inches square is a starting point, not a guarantee. Preserve the blank border and test the final print at the actual scanning distance and lighting.

Can I change my menu without making a new code?

Yes. Keep the same menu URL and update its content. A static QR code cannot change its encoded address after printing.

Where should the code point?

Prefer a stable menu page on your own domain. Make sure it opens on a phone without a login or permission request.

Can I track how many people scan it?

UTM tags can identify attributed menu visits in your analytics, not an exact scan count or a count of unique diners. The static code itself does not collect data.
