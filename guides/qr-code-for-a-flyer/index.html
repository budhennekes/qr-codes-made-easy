What to link (and why a live page beats a raw file)

A flyer usually needs one of three things behind the code: an event or RSVP page, a menu or product page, or a longer document like a full schedule or spec sheet. Whatever it is, point the code at a page rather than trying to cram everything the flyer can't fit into the pattern itself.

My honest take: link something you can update after the flyers are printed. Event details change, a sold-out class fills up, a special ends early. A code that points at a page you control lets you update the destination without reprinting a single flyer, since the code only holds the address, not the content behind it. If the endpoint is a document rather than a page, our QR code for a PDF guide covers hosting and sharing settings. If it's a form, see QR code for a Google Form.

How big the code needs to be

Flyers are read from close range, usually the one to two feet of someone holding it or standing in front of a stack on a table. Our QR print-size guide puts that scan distance at a minimum print size of about 1.5 x 1.5 inches (4 x 4 cm), using the general 10:1 rule (divide the scan distance by 10 to get the minimum width). Go bigger if the flyer will also live on a wall or a bulletin board a few feet further away than a handout.

Undersized codes are the single most common failure on flyers, because a full page of headline, photo, and body copy tempts designers to shrink the code to make room. Resist that. A code under an inch fails far more often than one at an inch and a half, and a flyer that fails to scan has wasted the print run just as surely as one nobody read.

Where to place it, and what kills the quiet zone

Put the code in a corner or a dedicated panel, not layered over a photo, a gradient background, or busy body copy. Scanners rely on the plain, empty border around a code, called the quiet zone, to find where the pattern starts. DENSO WAVE, the company that invented the QR code, specifies that this margin needs to be four modules wide on all four sides. Crop that margin to fit a tight layout, or let a headline crowd right up against the code, and a scanner can miss the code before it even tries to read it.

Give the code its own clear box: a plain background, the required margin intact, and a short instruction next to it like "Scan for tickets" or "Scan the full menu." A code with no label makes people guess what they're about to get, and a guessed scan is a skipped scan.

Common flyer mistake: a designer drops the code onto a busy photo or a dark background to match the layout, then flips it to light-on-dark to "fit." Both choices cut contrast and can stop a scan. Keep it dark modules on a light, plain patch, even if that means a small white box sitting on top of the photo.

Bleed, trim, and folds

If the flyer goes to a commercial printer, it gets trimmed to its final size after printing, and that trim line moves slightly from sheet to sheet. Print shops commonly work with a 0.125 inch bleed (artwork extends past the trim edge so there's no white sliver after cutting) and keep important content inside a 0.25 inch safe zone from the trim line. A QR code, including its quiet zone, belongs well inside that safe zone, not near the edge where a routine trim variance could shave into the very margin the code depends on.

The same logic applies to folds. On a tri-fold or bi-fold flyer, never let the code straddle a fold line. A hard crease through the middle of a QR code can distort or obscure enough modules to break the scan, and it also makes the flyer awkward to hold flat for scanning. Place the code inside a single panel, with room to spare from the fold.

  1. Start with dark on light. It's the combination phone cameras read fastest, and it holds up under the mixed lighting of a table, a bulletin board, or someone's hand.
  2. Keep the link short and clean. A shorter link needs fewer modules, which keeps the printed pattern simpler and more forgiving at flyer scale. Our QR code colors guide covers which combinations scan reliably if you want to match a brand palette.
  3. Download SVG for the print file. It stays crisp at any size the layout software scales it to, so the same file works whether the flyer prints at half a page or a full sheet. PNG is fine for a digital-only version shared as an image.

The 60-second print-proof protocol

Before a full print run, export the final file, drop it into the actual flyer layout at real size, and print one proof, folded the way the finished piece will be folded. Scan the proof with two different phones, once in good light and once in the dimmer, mixed lighting of wherever the flyer will actually sit (a table, a bulletin board, a stack by a register). Confirm it opens the right page, not a placeholder or an old draft.

If a proof won't scan, work through the troubleshooting checklist before committing to the full run; size, contrast, and a cropped quiet zone cover most flyer failures. Also plan for the flyer's second life: flyers get photocopied, faxed, or scanned into a phone gallery more than most printed pieces, and each generation loses a little sharpness. A code that's comfortably sized and high-contrast on the original survives a copy of a copy far better than one printed at the bare minimum.

Where a flyer QR code actually earns its spot

  • Event flyer: link to an RSVP or ticket page, and consider a Google Form if you're collecting a headcount.
  • Sale or promo flyer: link to the current offer page so the code stays accurate even after the promotion changes.
  • Class, workshop, or community flyer: link to a sign-up page, replacing a phone number nobody wants to type in by hand.
  • Real estate or yard-sign flyer: link to the full listing or a spec sheet PDF too long to fit on the printed page.

Whatever the use, tell people what scanning gets them. "Scan for the full menu" or "Scan to RSVP" beats a bare code every time, since a labeled code tells someone the two-second commitment is worth it.

FAQ

How big should a QR code be on a flyer?

At least 1.5 x 1.5 inches (4 x 4 cm) for a handout scanned from one to two feet away. Go bigger if the flyer will also be posted somewhere people view it from further back.

Where on the flyer should the QR code go?

A corner or a dedicated panel with a plain background, clear of photos, headlines, and page edges. Keep its full quiet zone (a blank margin four modules wide) intact.

Can the QR code cross a fold line?

No. A crease through the code can distort enough modules to break the scan. Keep the code inside a single panel on a folded flyer.

What should a flyer's QR code link to?

A page you control, like an event, sign-up, or offer page, rather than content baked into the code. That way you can update the destination after the flyers are printed.

Do I need extra margin for printing and trimming?

Yes. Keep the code and its quiet zone well inside the flyer's safe area, typically at least a quarter inch from the trim edge, since commercial trimming can vary by a fraction of an inch sheet to sheet.
